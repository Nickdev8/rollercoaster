# Rollercoaster Sketch Demo

A lean Godot prototype that lets you hand-draw rollercoaster tracks and watch carts ride them in real time. This started as a simple experiment in procedural paths and physics—you sketch, the engine simulates.

## Features
- **Freehand track drawing**: Click and drag to draw smooth rollercoaster rails.
- **Real-time physics**: Carts automatically follow your spline with gravity and momentum.
- **Quick resets**: Tweak your design on the fly without restarting the project.

## Controls
- **Draw**: Hold **Left Mouse Button** and drag to sketch track.
- **Launch**: Press **Space** to spawn and release a cart.
- **Reset Carts**: Press **R** to respawn all carts back at the start.
- **Clear Canvas**: Press **C** to erase your current track and start over.
- **Zoom / Pan**: Use **Mouse Wheel** and **Right Mouse Button + drag**.

## Getting Started
1. **Requirements**: Godot 4.0 or later.
2. **Clone**:
   ```bash

3. **Open**: Launch the `project.godot` file in the Godot editor.
4. **Play**: Hit **▶️** to start the scene and begin drawing!
